# RLP 玻璃检测分析工具

无需安装、无需联网的中文 CSV 分析网页。下载 `index.html` 后，用 Chrome、Edge 或 Firefox 打开即可使用；也可将仓库作为静态网站部署。没有 CDN、第三方脚本、后端或网络请求。

## 使用

1. 打开 `index.html`，点击“选择 CSV”，一次选择多个文件；可重复添加不同日期的数据。
2. 左侧按**文件内部检测日期**分组，勾选日期或当天的个别文件。跨日文件会出现在对应多个日期下，选择只影响该日的记录。
3. 修改 RLP 和平行度上下限，结果实时重算。上下限均包含边界。空值、非数字、上下限反置时暂停显示判定。
4. 查看三波段 L/M/R 曲线、左右平行度曲线、日汇总。支持条码或型号搜索、综合结果筛选。
5. 点击检测记录查看三点明细；悬停曲线点查看原始值；导出当前筛选汇总（包含来源与使用的公差），或打印 / 保存 PDF。

文件数据只在浏览器内存处理；刷新页面后需要重新选择文件。工具不内置生产数据，也不保存到浏览器存储。

## 默认公差与判定

| 项目 | 默认下限 | 默认上限 |
| --- | ---: | ---: |
| 470 nm | 13.5 | 17.5 |
| 530 nm | 18 | 22 |
| 630 nm | 18 | 22 |
| LeftDis、RightDis（各自） | 3 | 7 |

630 nm 默认公差按用户重复填写的 530 nm 项推定为 20±2。测量单位以设备定义为准，源 CSV 未声明单位。

- 一次检测由检测时间、工位、型号、条码组合识别。同一玻璃不同时间的复测分别保留；不自动选末次结果。
- 位置通过 `MeasurementPosition` 的 `_L`、`_M`、`_R` 后缀识别。三个点的三个波段共九个值全部在公差内，RLP 才合格。
- 平行度左右值必须各在公差内且同次三行一致，原始 `DepthResult` 必须一致且为 `OK`。原始 `NG` 即使数值在当前公差内也保留为不合格；修改公差不会覆盖设备判定。
- RLP 与平行度均合格才判整次检测合格；任意确定 NG 则不合格；缺点、缺值、位置或数据冲突、缺少原始判定等情况显示待判定。
- 未提供设备完整判定算法，因此工具不会从 LeftDis/RightDis 反推或覆盖原始 DepthResult。日汇总的合格率按全部选中检测次数计算，包含复测，不能直接作为出货最终良率。
- 完全相同的标准字段记录跨文件去重，保留所有来源文件。相同时间/位置但数值不同的冲突记录保留并阻止误判合格。
- 横轴按内部时间排序，不按文件名或导入顺序排序；保持源时间，不推定时区。跨日期不连线，同日连线只辅助看趋势，不代表连续测量或同一片玻璃变化。

## 支持的 CSV

必需列：

```text
Date&Time,WorkCenter_Code,Part_No,Barcode_No,MeasurementPosition,470nm,530nm,630nm
```

平行度列：`LeftDis,RightDis,DepthResult`。缺少这些列的旧版 CSV 仍可绘制 RLP，但综合结果不会判合格。

时间格式为 `YYYY-MM-DD HH:mm:ss` 或 `YYYY-MM-DDTHH:mm:ss`；CSV 支持 UTF-8（含 BOM）、GB18030、CRLF、引号转义及引号内换行。格式不合法的文件会单独报错，其他合法文件继续导入。相同名称且内容相同的文件跳过，文件名相同但内容不同的文件仍可导入。

CSV 字段作为文字或数值处理，不作为指令或 HTML 执行。导出对电子表格公式前缀进行转义。

## 验证

无需安装依赖，使用 Node.js 18 或更新版本：

```sh
node tests/analysis.test.cjs
```

包含十项测试：公差边界、RLP/平行度超限、原始 NG、缺值缺点、跨文件去重及来源、复测保留、冲突数据、多日期筛选与排序、CSV 解析、无效数据及导出转义。

当前实例另以 Chromium 验证了 16 份实际文件导入、文件筛选、全部选择/取消、公差无效时暂停判定、结果筛选、重复文件跳过、明细查看和 CSV 导出。生产文件及测试导出不纳入仓库。
